# 管道标注绘制流程（线框示意）

```
用户操作
   |
   v
打开 markpipeform.pmlfrm
   |
   +--> !!updatembdfiles()      // 同步最新配置/脚本
   |
   +--> 读取配置
   |       |- !!getattlist('bran')           // 属性列表
   |       |- form/setting/markpipeformSetting.txt
   |       |- files/frame*.txt (图纸/校审模板)
   |
   +--> 选取分支 AddCE/Addlist
           |
           v
      coll all bran for ce               // 收集分支
           |
           v
      构造 object isobran(bran,...)
           |
           +--> getatts()/split()        // 读取分支属性/几何
           +--> sumMaterials()/getspecialMaterials()
           +--> getwelds()/getzyjc()
           +--> getcuttubi()             // 直管长度
           +--> getdrawinginfojson()/getproofreadingjson()
           |
           v
      UI 列表填充 (属性/材料/焊缝/直管/在役)
           |
           v
用户点击 drawall()/draw(type)
           |
           v
    遍历 brandatas (每个 isobran)
           |
           +--> 设置绘制参数 (cheightbili/autocheight/... from form)
           +--> isobran.draw(type or ALL)
           |       |
           |       +--> 计算布局/方位/尺寸点
           |       +--> 生成尺寸、标签、焊缝标注对象
           |       +--> wronglines 收集异常
           |
           +--> （可选）clearcontent() 清理中间数据
           |
           v
    setfunctionlist()    // 汇总已生成的标注对象
           |
           v
    writeerror()         // 记录错误日志
           |
           v
    enhance/unenhance    // 按列表高亮选中

（可选导出）
   |
   +--> generatefiles()/Json()
   |       |
   |       +--> isobran.generatejsonattrvm() // 产出 JSON/RVM/ATT 路径
   |
   +--> toTplant()/jsontotplant
           |
           +--> getrvm/getatt/getjson -> updatefiles(ApiRequest) 上传
```

要点
- 数据来源：E3D 模型分支/构件（coll all）、本地 CSV 物料库（inputdata）、图纸/校审模板文件。
- 绘制依赖 isobran 内部几何计算；UI 仅传递参数与触发。
- 导出链路复用 export 与 totplant 模块，可独立于绘制调用。
