# 标注重构开发计划（管/支标注 + bevy_measurement）

## 架构线框
```
[UI/命令层 (egui/bevy UI)]
        |
        v
[Orchestrator/Pipeline]
        |
        +--> [DataProvider Trait] ----> aios-core/E3D 查询
        |          |
        |          +--> MaterialRepo (CSV) / TemplateRepo (txt)
        |
        +--> [Domain]
        |       - BranchCalculator（原 isobran 逻辑）
        |       - Exporter（JSON/RVM/ATT）
        |       - TypeResolver / AttrResolver
        |       -> 输出 Vec<MeasurementCommand> + 导出结果
        |
        +--> [MeasurementMapper]
        |       -> MeasurementMsg (Create/Update/Delete)
        |
        +--> [Uploader Trait]
                -> TPlant/自定义
        |
        v
[Bevy 系统]
  - 消息：MessageWriter/Reader<MeasurementMsg>
  - 渲染：bevy_measurement + 自定义组件
  - 状态：BranchId/MeasurementKind tag 管理显隐与清理
```

## 开发阶段与任务
1. **接口设计（1-2 天）**
   - 列出 PML 数据点 → Rust 能力映射：分支/成员/规格/几何/属性、物料库、模板、项目元数据。
   - 定义 traits：`PipeDataProvider`、`MaterialRepo`、`TemplateRepo`、`TypeResolver`、`Uploader`。
   - 定义数据模型：`BranchData`、`MemberData`、`WeldData`、`MeasurementCommand`、`ExportResult`、`PipelineEvent`、消息 `MeasurementMsg/MeasurementError`。

2. **数据层实现（3-5 天）**
   - 在 aios-core 提供 `PipeDataProvider`（映射 coll all/属性读取/过滤/within volume）。
   - 实现 `MaterialRepo`（读取 `inputdata/<proj>/*.csv`，缓存）与 `TemplateRepo`（frame/proofreading 等）。
   - 写 MockProvider 便于单测。

3. **Domain 迁移（5-8 天）**
   - 将 isobran 关键算法迁移为 `BranchCalculator`：分支解析、材料汇总、焊缝/切管、错误收集。
   - `MeasurementMapper`：几何 → `MeasurementCommand`（线段、文字、箭头、辅助点、样式）。
   - `Exporter`：输出 JSON/RVM/ATT（返回路径/Buffer）。
   - 单测：用模拟分支+物料校验材料/焊缝/测量指令结果。

4. **Bevy 集成（3-5 天）**
   - 插件系统：
     - A: `MessageReader<MeasurementMsg>` → 生成/更新/删除测量实体（bevy_measurement）。
     - B: `MessageReader<MeasurementError>` → UI/日志。
     - C: 清理/显隐（按 BranchId/MeasurementKind）。
   - UI 面板：参数设置（文字比例/颜色/忽略线）、触发 Pipeline。
   - 异步查询用 `RsTokioRuntime.spawn_auto`，回主线程写消息，遵守 MessageWriter 串行约束。

5. **导出与上传（2-4 天）**
   - UI 接入 `Exporter`，显示进度/路径。
   - `Uploader`：TPlant 适配层（可先 mock），配置地址/鉴权，错误反馈消息化。
   - 端到端测试：选分支 → 标注 → 导出 → 上传。

6. **配置与工具（1-2 天）**
   - AttList/Setting/模板外置为 toml/json，可热加载；提供默认值。
   - 统一 `PipelineEvent::Progress/Warning/Done`，UI 订阅。

7. **验证与优化（2-3 天）**
   - 性能：大分支查询/渲染耗时分析，必要时增量绘制。
   - 异常处理：缺材/缺几何/权限错误的提示与降级。
   - 文档：更新使用/配置/测试说明。

## 优先级与风险
- 优先完成 traits + DataProvider，确保 Domain 可脱离 PML 运行。
- 风险：E3D 查询映射不全 → 提前验证分支/规格/geom 接口；TPlant 协议变化 → Uploader 抽象后再适配。
