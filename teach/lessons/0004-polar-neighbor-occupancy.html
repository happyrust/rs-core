Lesson 0004 · 切段之后的空间影响

邻段如何互加 polarcyli？

isoline 切好、对象归好之后，相邻直段还会把对方当成障碍柱塞进 PolarSystem。 本课钉住：何时加、加什么、隔一段近折返时为何再加粗。

本课只钉一件事：getisolines 末尾（构造完每条 isoline 时）的邻段占位逻辑。 不讲 getBestPosAndOri 九步搜索细节。

为什么要管这个

弯头切开后，两段在空间上拐了弯，但标注仍会争同一侧空间。 PML 的做法：把上一段管柱加进当前段的 Polar，把当前段管柱加进上一段——互相挡路，避免尺寸画进邻管里。

源： getisolines 构造循环内 x > 1 且 usepolarsystem（约 1726–1780 行）。 旧路径则互加 isoUsedDir（同段逻辑的非 Polar 版）。

知识：两层互加

① 相邻段（恒做）

上一段 → 当前
用上一段 obstline 中点、pipedir.opposite()、od、高度=obstline.length 造 polarcyli，current.polarsystem.add(..., true)
当前 → 上一段
对称互加；但若当前柱高 ≤ 1（注释：olet at cap）则不加回去
坏柱
直径或高度近 0 → 画调试线、$p pre isoline is bad、return false

② 隔一段近折返（条件做）

当 x > 2（至少第三段）时，再看「当前」与「上上段」：

angle = nextpipedir.angle(prepipedir)   // 当前方向 vs 上上段方向
dis   = isolines[x-2].line.distance(current.line)

if angle > 160°:                       // 接近折返平行（反向）
  if dis < current.od * 15:
      把上上段柱（od×1.5）加进当前 Polar
  if dis < 上上段.od * 15:
      把当前柱（od×1.5）加进上上段 Polar（高度>1 才加）

直觉：U 型近折返时，隔一段的两直段几乎平行且靠得很近，尺寸更容易互相穿模，所以用加粗 1.5×od 的柱互相警示。

和 mission 的钉子： V2 若只切段、不做邻段/隔段障碍注入，弯头附近尺寸方向会对，但容易压到邻管。 对齐 PML 时，占位与切段是一套的。

技能：判要不要加
