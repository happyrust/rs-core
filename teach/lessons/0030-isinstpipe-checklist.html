Lesson 0030 · 仪表管开关速查

isinstpipe 开关清单

判定极简单：SITE 名含 INST → 仪表管。 之后整条 BRAN 标注链靠这个布尔决定「画 / 不画 / 换策略」——不必背文件行号，背类别即可。

isobran.setisinstpipe()： name of site 的 upcase().match('INST') 非 0 → true。 再传给每个 isoline(..., isinstpipe, ...)。

清单 A · 仅工艺管才做（.not()）

类别 典型行为 读图观感

弯头旁 弯段两点距>1 才补弯向；PE 标高类 tag（EM9） 仪表弯头旁信息更少
元件标签 geteltag 仪表管跳过这批 eltag

导出 zyjc 等工艺 JSON 块 仪表 JSON type 走 EM9PIPE

清单 B · 仪表管才做 / 换策略
