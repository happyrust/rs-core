Lesson 0009 · 动码前的设计

写一份 extract_isolines 改动提案

Mission 成功标准之一：能指出 V2 与 PML 切段差异，并知道改哪一层。 本课练写提案——先对齐语义，再谈 PR；避免「把 5° 改成 1°」式空拧。

本课只钉一件事：提案五段结构（背景 / 语义差距 / 目标行为 / 非目标 / 验收）。 不在本课直接改仓库代码。

现状一句话

// branch_calculator.rs · extract_isolines
angle < 5° || angle > 175°  → 视为同向，并入当前 isoline
否则                         → 新开 isoline

输入：LayoutResult.linear_dims（已是排好的段）
缺失：apos/lpos、贴拐点、桥接 mem、ELBO/BEND 类型

PML 真值： getisolines · 课 0001–0002 · 差异单 0008

提案模板（推荐结构）

  1. 背景：哪类 bran 失败（大弯并段 / 上游未断开）。
  2. 语义差距：对照 PML 三条岔路 + 桥接；写明 V2 缺哪些输入。
  3. 目标行为：用可测试句子写「给定 mem 序列与几何，应输出 N 段且桥接成员为…」。
  4. 非目标：本 PR 不做 Polar 邻段、不改 lindim、不改前端。
  5. 验收：单元测试表（含贴拐点不切、桥接双含、大转角必切）+ 1 条样例 bran。

两种改法，提案里必须二选一（或分阶段）

方案 α · 加固 extract（仍吃 LayoutResult）

  • 适用：上游已在弯头断开，仅合并逻辑过宽/过窄。
  • 风险：无 apos/lpos 时仍无法复现「贴拐点不切」。

方案 β · 下沉拆解（吃 BranchMember / 类型）

  • 适用：上游把 168° 弯抹成近共线（第 8 课陷阱）。
  • 对齐 PML：在成员遍历层做桥接切段，再生成 dim；extract 只做校验。
  • 工作量大，但才是 mission 长期解。
推荐默认立场： 先用差异单证明是 α 还是 β；证据不足时先 β 调查上游，不要先拧角度魔法数。

示范：可粘贴的短提案骨架

## 背景
样例 bran X：PDMS 3 段主尺寸，V2 2 段；转角处为 BEND。

## 语义差距
PML getisolines 以方向变化 + apos/lpos 桥接切段；
V2 extract_isolines 仅根据相邻 linear_dim 方向角合并，
且依赖 LayoutResult 是否已在弯头断开。

## 目标行为
- 给定含 BEND 且 apos/lpos 分离的成员序列 → 输出桥接两段
- lpos 贴上一拐点 → 不新开段，仅更新离开方向
- 回归：原共线多 dim 仍合并为 1 段

## 非目标
不改 polar 邻段占位；不改 small_dim 常数；不改前端。

## 验收
- 单测：同向合并 / 桥接切开 / 贴拐点不切
- 样例 bran X 段数与 PDMS 一致
- cargo check -p …（按仓库约定，不默认 test）

技能：审提案

小测（3 题）

Q1. 证据显示 Layout 在弯头两侧方向仅差 2°。提案应倾向？

Q2. 好提案里「非目标」的作用是？

Q3. 验收里最应包含的切段用例是？

作业

按骨架写一版「短提案」（可针对假想 bran），贴到对话； 我按五段结构批：缺证据、范围是否膨胀、验收是否可测。

也可说「按方案 β 帮我扩一版实施步骤（仍不动码）」。
