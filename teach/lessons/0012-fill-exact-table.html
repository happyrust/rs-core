Lesson 0012 · P0 → P1 之间

给玩具 bran 填 BranchMemberGeom 表

词典有了。本课练填表：把成员序列落成 P0 字段行，并标 Exact / ApproximateStartEnd——这是 P1 单测输入的来源。

本课只钉一件事：能独立填完一张成员几何表，并说清每行质量标记为何。 对照：P0 词典 · 课 2 玩具 bran

玩具 bran（与课 2 同构）

假设数据源只有 start/end + leave/arrive 轴（常见 V2 现状）：

示范填表（质量列）

refnoarrive_posleave_posposGeomQuality备注
T1startend中点Approximate直管通常可接受
EAstartend中点或 Bend.vertexApproximate* 若有 BendData.vertex → 升 Exact 候选
EBstartend中点Approximate end≈start+短向量 → 贴拐点易判真

*若 Surreal/PDMS 导出补齐真 apos/lpos/pos，整行改为 Exact，P1 才与 PML 主切完全同构。

填完后应能推出的切段（对照课 2）

allarr[1] = [HEAD, T1, W1, EA]     // EA 桥接切开
allarr[2] = [EA, T2, EB, T3, TAIL] // EB 贴拐点 → 不新开

用 Approximate 表手推时：EA 的 start/end 分离大 → 主切成立； EB 的 leave_pos 贴近上一拐点（800 vs 810）→ 只改方向。 若 Approximate 映射把 EB 的 lpos 算错，会误切成 3 段——这正是要标质量的原因。
