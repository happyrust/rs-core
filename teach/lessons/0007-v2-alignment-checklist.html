Lesson 0007 · 收束 Mission

对照 V2：你现在能查什么？

Mission：对齐 PML，校验/移植 extract_isolines 与尺寸车道语义。 本课把前 6 课压成可执行 checklist——对着一条真实差异，逐项打勾。

本课只钉一件事：拿到「V2 切段/尺寸看起来不对」时，按表排查，而不是凭感觉改阈值。

A. 切段（第 1–2、4 课）

  • [ ]PML 入口是 dir.angle(ldir) > 0.01 + apos/lpos，不是 type==ELBO。V2: extract_isolines 用角 <5° 或 >175° 视为同向。
  • [ ]弯头桥接：构件同时在上一段末、下一段首。查 V2 IsolineInfo.mems/点列是否丢桥接点。
  • [ ]贴拐点只改方向、不新开段（第 2 课 ELBO-B）。V2 无「贴拐点」分支 → 易多切。
  • [ ]邻段/隔段 polarcyli（160° + 15×od，隔段 1.5×od）。V2 enhance 若未注入邻段障碍 → 方向对但压邻管。

B. 归段（第 3 课）

  • [ ]有名对象走 mems；弯头 leg（elboname）走投影+近平行。仅最近点归段会落错 leg。
  • [ ]双候选：焊缝字看距离；其它看更水平 pipedir。固定选前一段会偏。

C. 尺寸车道与小尺寸（第 5–6 课）

  • [ ]PML 径向：od + cheight×1.2×(dimtimes-1)。V2 默认 od/2+cheight+…；对齐时开 use_pdms_offset_formula。
  • [ ]twoormoredims → 主尺寸 dimtimes=2。查 ATTA 子尺寸是否抬层。
  • [ ]小尺寸：0.8 getgoodcheight、下限 0.5、错层 1.2×cheight×level。V2 small_dim.rs 已对齐这组常数——差异多在输入点列。

推荐排查顺序（技能）

1. 段数对不对？     → checklist A（先手推 allarr）
2. 对象在不在对段？ → checklist B
3. 偏移层对不对？   → checklist C（dimtimes / 公式开关）
4. 字是否错层/加号？→ small_dim / adjustweld 输入

V2 入口： src/mbd/v2/branch_calculator.rs（extract_isolines ≈5°）、 src/mbd/v2/small_dim.rs、 config use_pdms_offset_formula

验收小测

你能否独立排查？（3 题）

Q1. V2 把 170° 弯头并成一段，最该先查哪条？

Q2. 段数对、但弯头 leg 尺寸画到另一直段，优先查？

Q3. 要对齐 PML 径向偏移，V2 配置应？

Mission 收束

若三题都能稳定答对，你已具备 mission 写的能力： 对照源码判定 V2 切段/车道对不对。 下一步可以是：挑一条真实 bran 做差异单，或改 extract_isolines 提案（改代码前先写 learning-record）。
