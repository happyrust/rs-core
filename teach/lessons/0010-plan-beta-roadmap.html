Lesson 0010 · 方案 β 路线图

下沉拆解：实施步骤（不动码）

第 9 课选 β：在成员/几何层复现 getisolines 桥接切段，而不是只拧 extract_isolines 角度。 本课把 β 拆成可排期的阶段——仍停在设计，方便你评审后再开 PR。

本课只钉一件事：能说出 β 的阶段顺序、每阶段交付物、以及「先不做」的边界。

总原则

  • PML 真值：isobran.getisolines（课 1–2）
  • 输入要比 LayoutResult.linear_dims 更「上游」：成员名、类型、ldir/adir、apos/lpos/pos
  • 输出：与 isoline 同构的段描述（mems 桥接、pipedir、端点），再交给现有 dim/Polar 管线
  • 遵守 AGENTS：默认 debug / 优先 cargo check；失败写 suppress 原因

阶段路线

P0 · 数据契约

定义 BranchMemberGeom（或扩现有 data_source::BranchMember）： name、type、ldir、adir、apos、lpos、pos。 写清：缺字段时是 skip、wrongline，还是降级到角阈值。 交付：类型 + 一句字段词典（可放 reference）。

P1 · 纯函数切段

实现 split_isolines_pml(members) -> Vec<IsolineMems>， 先只覆盖弯头主路径（课 1 三条岔路 + 桥接 + 贴拐点）， 不接 PCOM / special element。 交付：单测表（同向不切 / 桥接切开 / 贴拐点不切 / 通过件挂袋）。

P2 · 接到管线

在 V2 pipeline / BranchCalculator 入口：有成员几何则走 P1； 否则 fallback 现有 extract_isolines（保持旧样例不崩）。 交付：feature 开关或显式 API；对照 1 条样例 bran 段数。

P3 · 邻段占位（可选下一 PR）

对齐课 4：相邻 polarcyli；隔段 160° + 15×od + 1.5×od。 明确非本 β-MVP：可列进非目标，避免第一 PR 过大。

P4 · PCOM / special（更后）

isrjpcom / ispipespecialelement 分支。 与弯头主路径分离，防止测试矩阵爆炸。

P1 算法核对表（对着写单测）

for mem in branMems:
  Head/Tail/通过件(ATTA,TUBI,OLET,WELD) → 课 2 规则
  PCOM → P4 再说（P1 skip 或 wrongline 策略写死）
  dir∠ldir > 0.01:
    ① 近 180° 校正 → skip
    ② apos↔lpos>1 或角>10°:
         lpos 贴拐点 → 只改 ldirs
         else → 桥接切开（mem 双含）
    ③ adir∠memldir > 100 → 强制再切（知悉可叠切）

风险与顺序

  • 无 Surreal/PDMS 几何字段 → P0 先打通数据源，否则 β 做不了
  • 先 P1 单测绿灯，再 P2 接线——避免「接上了但语义未证」
  • 第一 PR 建议：P0+P1+最小 P2；P3/P4 另开
和 α 的边界： 若差异单证明 Layout 已正确断开，只需调合并——走 α，不必上 β。 β 的触发条件是：成员层有弯，但 linear_dims 已被抹直。

技能：排期判断
