Layout / P0 → SplitMember → 袋子

把课 57 的「三件事」落成表。对照 P0 字段词典 与已实现的 SplitMember。

① 入：几何 → SplitMember

SplitMember PML / P0 缺了怎么办
refno mem 名 无法桥接双含 → issue + 回退
kind Head/Tail/Tubi/Elbo/… 未知 → Other；无 leave 则跳过切支
leave_dir ldir 非 Head/Tail 必填；否则 issue
arrive_dir adir 近180/强制切不可用；仅能走②角阈
arrive_pos / leave_pos apos / lpos stick/近180 变钝；优先回退或 Approximate
pos pos of mem 桥接 turn 用 apos/lpos 中点顶上
geom_quality Exact / Approximate… Missing → 不走 P1

② 出：allarr → 段

P1 输出 主链需要
Vec<Vec<refno>> 每段有序成员列表（弯头可双含）
（隐式）段序 IsolineInfo 下标 / pipedir 取该段主导 leave
issues[] wronglines / 日志；非空可触发回退策略

③ 轴方向

P1 当前返回袋子，不单独返回 ldirs。 P2 映射时：每段取第一个非桥接重复之后的稳定 leave_dir， 或在 P1 扩展返回 ldirs: Vec<Vec3>（推荐下一小步）。

已实现类型：aios_core::mbd::SplitMember / p1_split::SplitMember（字段同构）。
