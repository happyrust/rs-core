为什么要返回 ldirs

PML 切段时同步维护 ldirs[]（每段离开方向）。 现在 P1 只回 allarr，P2 映射轴方向时只能猜。 本课设计：SplitResult { allarr, ldirs, issues }，与袋子等长。

规则（与实现对齐）

  • Head：ldirs.push(leave_dir)
  • ②/③ 桥接：新袋 ldirs.push(dir)
  • 贴拐点 / 近180：改 ldirs.last 与 run_ldir，不新增长度
  • Tail 收袋：不单独 push 方向

验收

assert_eq!(result.allarr.len(), result.ldirs.len());
// toy: ldirs[0]≈+X, ldirs[1]≈+Z
// colinear: 单段 +X
// variant: 三段，末段沿 EB leave
实现时可在 teach/p1_split 先加字段与断言；主链 P2 再读 ldirs。 说「实现 ldirs」即可动码。
