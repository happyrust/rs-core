第 68 课盘点出：P1 切段、P3 Polar 都各自绿了，但两者之间那座桥——归段——还没接（病例 2 的根源层）。 这一环的测资已经先落地：teach/fixtures/p4-put-into-isoline.json 两案已把字段与期望 goodx 钉清，等 Rust 去消费。 本课带你读懂这份 fixture,不写实现。

输入复用 P1 toy-bridge-and-stick 切出的两袋：
段0 mems=[HEAD,T1,W1,EA] · 段1 mems=[EA,T2,EB,T3,TAIL]——EA 被两袋共含,这正是双候选的来源。

案 1 · bridge-legs-and-material：五个对象，四种归法

对象类型 / 触发期望 goodx为什么
LEG-EA-IN ISOLEG · 有 elboname → 路径 A（弯头 leg） 段0 ori_zdir∠pipedir0=0<1° 且 attapos 投影在段0；对段1 折叠 90° 被拒
LEG-EA-OUT ISOLEG · leg 段1 只有段1 近平行且可投影（出侧腿）
DIM-UNNAMED name=null → 路径 A（投影） 段0 收集时即取最近：到段0 距离 120 < 段1 的 200，不进决胜块
MAT-EA ISOMATERIAL · 有名 → 路径 B 段0 adir∠ldir=90<179 → 不 break → 双候选；非焊缝字决胜：段0 oneangle=0（水平）胜段1 的 90
LOST-UNNAMED name=null，pos 在 [-200,…] skip 两段都投影不上 → 打印「Cant find good isoline」后跳过,不硬塞

期望袋：段0 = [LEG-EA-IN, DIM-UNNAMED, MAT-EA]；段1 = [LEG-EA-OUT]。

案 2 · weldtext-distance-and-slope-order：距离决胜 + 写入次序

对象类型 / 触发期望为什么
WTX-EA ISOWELDTEXT · 有名双候选 段1 · append · final_pos=[1110,0,400] 焊缝字按距离决胜：段1=20 < 段0=400；再 movedis 翻转：movedir∠showdir1=180>90 → 取反成 +X → 偏移 30
SLOPE-T2 ISOSLOPE 段1 · insert_front 直通件 adir∠ldir=180≥179 → 首命中 break（段1）；ISOSLOPE 用 insert(1) 排到袋首
WTX-ATTA-PAD ISOWELDTEXT · 挂 ATTA → 投影收集 段1 · append 两段都投影上,再按距离：段1=120 < 段0=130；此分支不看 samedirs
MAT-HEAD ISOMATERIAL · 名=HEAD 段0 · append HEAD/TAIL 免查 adir → samedirs 保持 true → 首命中 break,单候选直取

期望袋：段0 = [MAT-HEAD]；段1 = [SLOPE-T2, WTX-EA, WTX-ATTA-PAD]。 注意段1 里 SLOPE-T2 因 insert(1) 排在最前——写入次序也在断言里。
