Lesson 0006 · 尺寸实体最后一公里

lindim：小尺寸与加号焊

drawdim 只决定「尺寸线放哪、朝哪」。真正生成 PDMS LINDIM、处理「字塞不下」和「调整焊 +长度」，在 lindim.create → sepSmallDim。

本课只钉一件事：一段点列如何被拆成一行或多行 DIM，以及加号焊文字如何挤进宽度预算。

入口回顾

lindim(...) 构造
  → create()
       changeCheightAuto()     // 整链先可能整体缩字高
       allRows = sepSmallDim() // 按段拆行 / 错层
       对每一行: new lindim + dimpos…

源： MBD/object/mbd/lindim.pmlobj · 综述：BRAN 全景文档 §3.3（Rust small_dim.rs 同源语义）

知识：开关都关时

若 sepSmallDim 与 changeCheightAuto 都未启用：整条点列一行吐出，字高不变。 有任一开关为真，才进入分段决策树。

知识：逐段「字宽 vs 段长」

对相邻点 points[x] → points[x+1]：

  1. 投影段长 dis（沿 ori.xdir）
  2. 数字串宽度 len = mbdtextlen(数字) * cheight
  3. 若该段上有 adjustwelds 落点：累加 adjustlen，拼 " +N"，并把加号字宽（可乘 plusstringcheightbili）并入 len；标记 plus=true
  4. 若 len ≤ dis：累积到当前行
  5. 若 len > dis（塞不下）：
    • 先收口此前已累积的「正常行」
    • 对这一小段：若允许自动缩字高，用 getgoodcheight(..., 0.8)，下限 cheight × bili（默认 0.5）
    • 缩完仍不够，且允许 sepSmallDim：currentLevel++，沿 ori.ydir（或反向）偏移 cheight × 1.2 × level 错层
    • 不允许错层：仍放在原基线，用缩小后的字高硬塞
和 mission 的钉子： Rust V2 把同一决策拆成 small_dim.rs + expand_linear_dim_chain。 对齐时看三件事：宽度公式、0.8/0.5 系数、错层步长 1.2×cheight×level。

技能：判会不会错层

建议的一手材料

打开 sepSmallDim，盯 len gt dis 分支与 cheight * 1.2 * currentLevel。 对照第 5 课：车道解决「离管多远」；本课解决「字在尺寸线上怎么排」。

可给「段长 / 数字 / 是否有 +调整焊 / 两个开关」让我帮你判：缩字、错层，还是硬塞。
