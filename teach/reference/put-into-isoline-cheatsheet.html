Reference · putIntoIsoLine

归段速查

切完 isoline 之后，对象如何选中 goodx。

路径选择

name 空  OR  (ISOLEG 且 elboname 已设)
  → 路径 A 投影
否则
  → 路径 B mems 名匹配
     （ISOWELDTEXT + ATTA → 仍用投影收集候选）

路径 A（含弯头 leg）

  • 普通：line.onprojected(pos)，按距离排序取最近
  • 弯头 leg：折叠后 pipedir∠ori.zdir < 1°，且 attapos 可投影；按到 attapos 距离取近
  • 全无候选：打印并 skip

路径 B

  • mems.findfirst(name)；桥接件可命中多段
  • adir∠ldir < 179 → samedirs=false，不提前 break

多候选决胜

  • ISOWELDTEXT：距线段最近
  • 其它：pipedir 更接近水平（相对 U）

写入

ISOSLOPE / ISOADJUSTWELD / ISOMBDANGLE → insert(1)；其余 → append。
