BranchMemberGeom 字段词典

方案 β 的 P0：切段纯函数需要的成员几何契约。 对照 PML getisolines 与现有 v2::data_source::BranchMember。

目标类型名（提案）：BranchMemberGeom（可扩现有 BranchMember，不必另起炉灶）。 切段函数只依赖本表字段；缺关键字段时按「缺省策略」列处理。

1. 身份与类型

字段PML 来源现有 V2用途缺省策略
refno / name mem 名 / dbref BranchMember.refno 桥接双含、归段 mems 匹配 必填；缺失 → 整成员 skip + issue
member_kind type of mem；Head/Tail 伪成员 部分：arrive_noun；无统一枚举 通过件判定、P4 PCOM、弯头类型兜底 未知 → 当「普通变向件」走角度几何，不当通过件
order branMems 顺序 order 稳定遍历 按数组下标

2. 方向（切段入口）

字段PML现有 V2用途缺省策略
leave_dir ldir of mem leave_axis dir.angle(ldir) 入口；新段 pipedir 缺失 → 用 normalize(end-start)；仍无 → skip + issue
arrive_dir adir of mem arrive_axis 近 180° 校正；>100° 强制切 缺失 → 跳过①③，只靠 leave 与运行 ldir

3. 点位（主切 / 贴拐点）

字段PML现有 V2用途缺省策略
arrive_pos apos 近于 start（需确认语义） apos↔lpos；近 180° 时贴拐点判定 若仅有 start/end：约定 start=arrive、end=leave，并在 meta 标记 approximate
leave_pos lpos 近于 end 主切；贴上一拐点 (<0.1) 同上
pos pos of mem 无专用；BendData.vertex 部分覆盖 切开时写入 poss 的拐点 缺省 = arrive/leave 中点；弯头优先用 BendData.vertex

4. 通过件与伪成员

kind行为备注
Head开袋；poss←hpos；ldirs←hdirbran 级属性，非 DB 成员
Tail收口当前袋
ATTA / TUBI / OLET / WELD只 append，不切P1 硬编码集合
ELBO / BEND不靠 type 字符串进门；靠方向几何type 仅用于日志/兜底
PCOMP4；P1 可 issue「未实现」或降级几何见 isrjpcom / special

5. 与现有类型的缺口（P0 必须写进提案）

  • 缺口 A：apos/lpos/pos 三分量 vs 仅 start/end — 需数据源补齐或明确 approximate 映射。
  • 缺口 B：无稳定 member_kind 枚举 — 建议 enum MemberKind { Head, Tail, Tubi, Atta, Weld, Olet, Elbo, Bend, Pcom, Other }。
  • 缺口 C：BendData 与 members 并行 — P1 切段应以 members 序列为准，BendData 作 pos/角度校验。

6. 建议的 Rust 草图（非正式 API）

pub struct BranchMemberGeom {
    pub refno: String,
    pub kind: MemberKind,
    pub order: u32,
    pub leave_dir: Option<Vec3V2>,   // ldir
    pub arrive_dir: Option<Vec3V2>,  // adir
    pub arrive_pos: Option<Vec3V2>,  // apos
    pub leave_pos: Option<Vec3V2>,   // lpos
    pub pos: Option<Vec3V2>,
    pub outside_diameter: Option<f32>,
    pub geom_quality: GeomQuality,   // Exact | ApproximateStartEnd
}

pub enum GeomQuality { Exact, ApproximateStartEnd }

7. 验收（P0 完成定义）

  • 字段表评审通过（本文）
  • 从至少一条样例 bran 能填满 Exact 或显式 Approximate
  • 缺 leave_dir 时产生可机读 issue，不静默硬切
