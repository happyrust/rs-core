dimtimes 与径向车道

谁传入 dimtimes

mainDim && twoormoredims → 2
mainDim && !twoormoredims → 1
!mainDim (ATTA 子尺寸)   → 1

twoormoredims ← getAttaDims 产生了 ATTA 子尺寸

径向公式（PML）

radius_lo = od + cheight * 1.2 * (dimtimes - 1)
radius_hi = radius_lo + cheight

抑制与跳过

  • 轴向投影跨度 < 1 → return
  • twoormoredims && dimtimes==1 → 跳过 slope 辅助；非仪表管也跳过该层流向

lindim 分支

maxslope 已设 = 普通尺寸；否则 = 弯头 leg（可带 fake 调整焊长度）。
