isinstpipe 速查

判定

sitename = name of site of bran
isinstpipe = sitename.upcase().match('INST') ≠ 0

再传入每个 isoline(..., isinstpipe, ...) / polarsystem。

仅工艺管（isinstpipe.not()）

  • 收集：branmlabel、cutparts、ISOLEG 进 objects
  • 弯头：弯段两点距>1 补弯向；PE 标高 tag（EM9）
  • 标签：geteltag
  • 属性：ROOM_NO 等
  • 绘制：drawflow / TSPEC（且非 twoormoredims && dimtimes==1）
  • 导出：zyjc JSON 块

仪表管策略（isinstpipe）

  • 焊缝：EM4「偏 weld」——Head/Tail、OLET/TEE 等
  • pspec 取值路径不同
  • 进度 UI：markinstpipeform
  • JSON type：EM9PIPE
  • isoline 对 INST 类型 mem 有专支

与切段

getisolines 主逻辑工艺≈仪表；开关管绘制/收集，不另写一套角阈值。

支架 → marksupport，不在此表。
